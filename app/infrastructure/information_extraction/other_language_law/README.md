# 其他语种法规知识图谱抽取

本包实现“格式保持型翻译 -> 中文法规抽取”的其他语种法规抽取流程。

## 流程

```text
其他语种法规原文
  -> 逐行格式保持翻译
  -> 临时中文法规文件
  -> 复用 law_extract.ClauseExtractor
  -> 中文知识图谱 JSON / Neo4j 入库
```

## 关键约束

1. 原始法规文件不被修改。
2. 翻译阶段尽量保留行数、换行符、缩进、标题、列表符号、条款编号和引用编号。
3. 不为其他语种单独设计知识图谱 schema。
4. 译文、翻译质量报告、抽取结果和抽取报告都应保留，便于人工审查。

## 主要文件

- `config.py`：模型、目录、缓存和翻译参数配置。
- `translator.py`：格式保持翻译、JSONL 缓存、本地 LLM 客户端。
- `quality.py`：译文行数、编号、前缀和疑似未翻译内容校验。
- `extractor.py`：翻译、校验、中文抽取和报告编排。
