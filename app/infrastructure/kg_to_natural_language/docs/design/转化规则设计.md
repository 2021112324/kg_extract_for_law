 

# 知识图谱数据转知识条目 转化规则（最终定稿）

> 依据：`汇总_实体属性关系清单.md` + 知识定义 + 6 类知识产出 + 已确认决策。
> 原则：**过滤无用属性 + 同类属性组装成一条完整知识 + 规则是知识不抛弃**。

---

## 0. 来源语境与输出优先级

1. `法规文件`节点作为主语生成的文件档案知识保持原句，不添加文件前缀。
2. `法条`、`条款单元`以及非法规文件节点发起的引用关系知识，统一通过`filename`关联法规文件节点。条款单元知识使用`在《{文件名称}》{单元编号}中，{知识正文}`格式；其他知识使用`在《{文件名称}》中，{知识正文}`格式。
3. 文件名称优先取法规文件节点的`文件全称`或`name`；无法匹配文件节点时，回退到去路径、去扩展名后的`filename`；无法获得有效名称时保留正文，不生成“未知来源”前缀。
4. 每条知识最多添加一次来源前缀，文件节点名称不得在前缀后机械重复。
5. 输出顺序调整为：法规文件档案知识、条款单元内容及启用的结构化规则知识、引用知识、法条效力范围知识。效力范围作为补充知识最后输出，但内容和数量保持不变。

---

## 1. 总原则

1. **知识是总称**，规则是知识的一种，不抛弃规则。
2. **过滤无用属性**：纯标签、摘要、结构标识、冗余原文、内部标识。
3. **同类属性组装**：被拆散的属性合起来，组装成"能回答一个完整问题"的一条知识。
4. **原文保留**：条款单元内容是规则原文，单独成一条知识。
5. **删除"包含/属于"层级关系**，保留"引用/涉及/依据"关系。

| 5 | **引用知识**         | 边关系（引用/涉及/依据） | ❌                                  | ≈ 349   |

**常量标志**：

```python

ENABLE_STRUCTURED_RULE_ASSEMBLY = True
```

**组装模板**（最多 4 条）：

```
1. 文件身份：{name}[（{文号}）]是[{发布单位}发布的]{文件性质}
2. 效力状态：{name}发布于{发布日期}[，{生效日期}生效]，{时效性}
3. 立法目的：{name}的制定目的是{制定目的}
4. 适用范围：{name}的适用范围是{应用范围}
```

**条件说明**（`[ ]` 内字段**不为空或 null** 时才添加）：


| 模板                 | 条件                                          |
| ---------------------- | ----------------------------------------------- |
| `[（{文号}）]`       | 文号不为空                                    |
| `[{发布单位}发布的]` | 发布单位不为空                                |
| `[，{生效日期}生效]` | 生效日期不为空                                |
| `3. 立法目的`        | 制定目的不为空（填充率 0.98，几乎恒有）       |
| `4. 适用范围`        | 应用范围不为空（填充率 0.91，为空则跳过整条） |

**规则知识组装模板**（`ENABLE_STRUCTURED_RULE_ASSEMBLY=True` 时）：

```
{适用主体}[在{适用前提}的情况下]{行为描述}[，其量化标准为{量化标准}][，{例外情形}的除外]。

```

**条件说明**（`[ ]` 内字段**不为空或 null** 时才添加）：


| 片段                                   | 添加条件                               |
| ---------------------------------------- | ---------------------------------------- |
| `[在{适用前提}的情况下]`               | 适用前提不为空                         |
| `[，其量化标准为{量化标准}]`           | 量化标准（量化条件.原文件）不为空/null |

| `[违反{条款单元}规定的，{法律后果}。]` | 法律后果不为空                         |

**量化条件解析**：量化条件是字符串形式的 Python 字典，先 `ast.literal_eval` 解析，提取 `原文件` 字段作为可读量化文本（如"100万元以下罚款"），丢弃 `最小值/最大值/单位/约束关系` 等结构化字段。

## 4. 关系处理规则


| 关系 | 主语→宾语              | 处理                 |
| ------ | ------------------------- | ---------------------- |
| 包含 | 法规文件→法条          | **删除**             |
| 包含 | 法条→条款单元          | **删除**             |
| 引用 | 条款单元→引用依据      | **保留** → 引用知识 |
| 涉及 | 条款单元→引用依据      | **保留** → 引用知识 |
| 依据 | 法规文件→法规依据      | **保留** → 引用知识 |
| 依据 | 条款单元→条款单元/法条 | **保留** → 引用知识 |

### 引用知识组装模板

**条款单元 -引用/涉及→ 引用依据**（按引用类型分支）：

```
引用类型 = 文件：{条款单元}{引用关系}{文件全称}，目的是{引用目的}
引用类型 = 条款：{条款单元}{引用关系}{文件全称}{条款编号}，目的是{引用目的}
```

**法规文件 -依据→ 法规依据**：

```
{法规文件名}依据{法规依据文件全称}制定
```

**条款单元 -依据→ 条款单元/法条**：

```
{条款单元名}依据{目标名称}
```
