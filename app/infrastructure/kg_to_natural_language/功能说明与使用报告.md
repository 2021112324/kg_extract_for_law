# 知识图谱导出与自然语言转换模块 功能说明与使用报告

## 1. 模块概述

本模块位于 `app/infrastructure/kg_to_natural_language/`，提供两个核心能力：

1. **知识图谱导出**：从 Neo4j 图数据库按标签导出节点和关系数据为 JSON 文件
2. **自然语言转换**：将导出的图谱 JSON 数据按法规类规则转换为结构化的自然语言知识条目

### 调用入口

```python
from app.infrastructure.kg_to_natural_language import process_graph

result = process_graph(
    tag="e1_行政监管规则_kg_586736132520148992",
    graph_type="行政监管规则"
)
```

## 3. 功能详解

### 3.1 知识图谱导出 (`exporter.py`)

**输入**：Neo4j 图谱标签（tag）

**流程**：
1. 每次执行前清空 `temp/json/`、`temp/txt/`、`temp/csv/` 下的旧数据
2. 通过 `GraphDatabase.driver()` 连接 Neo4j（复用 `.env` 中 `NEO4J_URI` 等配置）
3. 验证 Neo4j 连接可用性
4. 执行 Cypher 查询导出节点：`MATCH (n:<tag>) RETURN n`
5. 执行 Cypher 查询导出关系：`MATCH (n:<tag>)-[p]->(q) RETURN p`
6. 将 Neo4j Node/Relationship 对象序列化为标准 JSON 格式，写入 `node.json` 和 `edge.json`

**输出格式**（与 Neo4j Browser 导出兼容）：
```json
// node.json
[{ "n": { "identity": 123, "labels": ["标签"], "properties": {...}, "elementId": "4:..." } }]

// edge.json
[{ "p": { "identity": 456, "start": 123, "end": 789, "type": "包含", "properties": {...}, "elementId": "5:..." } }]
```

### 3.2 JSON → 自然语言转换 (`converter.py`)

**转换规则**：统一按「法律法规条款 / 行政监管规则」法规类规则处理。

#### 节点属性处理

| 节点类型 (label) | 处理规则 |
|---|---|
| **法规文件** | 合并"发布日期/生效日期/时效性"为一条 → `{name}的发布日期是{x}，生效日期是{y}，时效性是{z}`；跳过与 name 相同的"文件全称""文件别名"；**不添加** `{filename}中，` 前缀 |
| **法条** | 合并"编/章/节"为一条 → `{name}属于{编}{章}{节}`；跳过已在 name 中体现的"条"属性 |
| **条款单元** | 特殊属性转换：功能类型 → `是{value}类型的条款`；责任角色 → `在{name}条款中，主体的责任角色是{value}`；行为描述 → `涉及的具体行为是{value}`；例外情形 → `不适用于以下情形：{value}`；时间要素 → `涉及到的时间要素为：{value}`；其他信息 → `里包含的其他信息有：{value}`；量化特征+量化条件合并输出 |
| **法规依据 / 引用依据** | 跳过（由边关系处理） |
| **其他 label** | 通用格式 `{name}的{property}是{value}` |

#### 边关系处理

| 边三元组 | 处理规则 |
|---|---|
| 法规文件 - 包含 → 法条 | 聚合计数 → `{法规文件}包含{N}条法条` |
| 法条 - 包含 → 条款单元 | 聚合计数 → `{法条}包含{N}条条款单元` |
| * - 依据 → * | 普通关系句 → `{subject}{predicate}{object}` |
| 条款单元 - 涉及 → 引用依据 | 结合引用依据节点的"引用关系"和"引用目的" → `{subject}{引用关系}{object}，目的是{引用目的}`（引用目的为空时省略） |

#### 输出

- `temp/txt/<graph_type>.txt`：每行一条自然语言知识
- `temp/csv/知识条目统计.csv`：类型总条目数 + 各来源文件的条目数

## 6. 使用方式

### 完整流程（导出 + 转换）

```python
from app.infrastructure.kg_to_natural_language import process_graph

result = process_graph(
    tag="e1_行政监管规则_kg_586736132520148992",
    graph_type="行政监管规则"
)
print(result)
# {
#     "tag": "e1_行政监管规则_kg_586736132520148992",
#     "graph_type": "行政监管规则",
#     "export": {"node_count": 3321, "edge_count": 3417, ...},
#     "convert": {"total_entries": 30753, "source_files": 24, ...}
# }
```

### 仅导出（不转换）

```python
from app.infrastructure.kg_to_natural_language import export_graph

stats = export_graph("e1_行政监管规则_kg_586736132520148992")
# → temp/json/node.json, temp/json/edge.json
```

### 仅转换（已有 JSON）

```python
from app.infrastructure.kg_to_natural_language import convert_json_to_text

stats = convert_json_to_text("行政监管规则")
# 从 temp/json/ 读取，输出到 temp/txt/ 和 temp/csv/
```

### 清空临时目录

```python
from app.infrastructure.kg_to_natural_language import clear_temp_dir

clear_temp_dir()
# 清空 temp/json/, temp/txt/, temp/csv/ 下的所有文件
```
